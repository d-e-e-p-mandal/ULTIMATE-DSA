# C++ `std::vector` --- Part 4

# Iterators, Copy/Move Semantics & Allocators

------------------------------------------------------------------------

# Iterators

An iterator is an object that points to elements inside a container.

For `std::vector`, iterators are **random access iterators**.

Advantages:

-   Traverse elements
-   Modify elements
-   Use STL algorithms
-   Perform arithmetic (`+`, `-`, `<`, `>`)

------------------------------------------------------------------------

# Iterator Types

  Function      Description
  ------------- -----------------------
  `begin()`     First element
  `end()`       One past last element
  `cbegin()`    Const begin
  `cend()`      Const end
  `rbegin()`    Reverse begin
  `rend()`      Reverse end
  `crbegin()`   Const reverse begin
  `crend()`     Const reverse end

------------------------------------------------------------------------

## `begin()`

``` cpp
vector<int> v={10,20,30};

auto it=v.begin();

cout<<*it;
```

Output

``` text
10
```

------------------------------------------------------------------------

## `end()`

``` cpp
for(auto it=v.begin(); it!=v.end(); ++it)
{
    cout<<*it<<" ";
}
```

Output

``` text
10 20 30
```

------------------------------------------------------------------------

## `cbegin()` and `cend()`

Read-only iterators.

``` cpp
vector<int> v={1,2,3};

for(auto it=v.cbegin(); it!=v.cend(); ++it)
    cout<<*it<<" ";
```

Elements cannot be modified through these iterators.

------------------------------------------------------------------------

## `rbegin()` and `rend()`

``` cpp
vector<int> v={10,20,30};

for(auto it=v.rbegin(); it!=v.rend(); ++it)
    cout<<*it<<" ";
```

Output

``` text
30 20 10
```

------------------------------------------------------------------------

## `crbegin()` and `crend()`

Reverse const iterators.

``` cpp
for(auto it=v.crbegin(); it!=v.crend(); ++it)
    cout<<*it<<" ";
```

------------------------------------------------------------------------

# Iterator Arithmetic

``` cpp
vector<int> v={10,20,30,40};

auto it=v.begin();

cout<<*(it+2);
```

Output

``` text
30
```

Distance

``` cpp
cout<<v.end()-v.begin();
```

Output

``` text
4
```

------------------------------------------------------------------------

# Range-based Loop

``` cpp
for(int x:v)
    cout<<x<<" ";
```

Modify elements

``` cpp
for(int &x:v)
    x*=2;
```

------------------------------------------------------------------------

# Const Iteration

``` cpp
for(const auto &x:v)
    cout<<x<<" ";
```

Prevents accidental modification.

------------------------------------------------------------------------

# Copy Semantics

## Copy Constructor

``` cpp
vector<int> a={1,2,3};

vector<int> b(a);
```

Creates an independent copy.

------------------------------------------------------------------------

## Copy Assignment

``` cpp
vector<int> a={1,2,3};
vector<int> b;

b=a;
```

All elements are copied.

------------------------------------------------------------------------

# Move Semantics

Move transfers ownership of allocated memory instead of copying.

Requires

``` cpp
#include <utility>
```

------------------------------------------------------------------------

## Move Constructor

``` cpp
vector<int> a={1,2,3};

vector<int> b(std::move(a));
```

Typical result

``` text
a.size() == 0
```

The moved-from vector remains valid but its contents are unspecified.

------------------------------------------------------------------------

## Move Assignment

``` cpp
vector<int> a={1,2,3};
vector<int> b;

b=std::move(a);
```

Calls

``` cpp
operator=(vector&&)
```

------------------------------------------------------------------------

# Copy vs Move

  Feature                   Copy     Move
  ------------------------- -------- ----------------------------------
  Allocates new memory      Yes      Usually No
  Copies elements           Yes      Usually No
  Source retains elements   Yes      No (valid but unspecified state)
  Performance               Slower   Faster

------------------------------------------------------------------------

# When Move Happens Automatically

``` cpp
vector<int> create()
{
    vector<int> v={1,2,3};
    return v;
}
```

Modern compilers often apply copy elision or move semantics.

------------------------------------------------------------------------

# Allocators

An allocator manages dynamic memory for a container.

Template declaration

``` cpp
template<class T,
         class Allocator=std::allocator<T>>
class vector;
```

Default allocator

``` cpp
std::allocator<T>
```

------------------------------------------------------------------------

# `get_allocator()`

Returns the allocator used by the vector.

``` cpp
vector<int> v;

auto a=v.get_allocator();
```

Mostly useful when writing custom allocators.

------------------------------------------------------------------------

# Custom Allocator

``` cpp
template<typename T>
class MyAllocator;
```

Usage

``` cpp
vector<int,MyAllocator<int>> v;
```

Common uses

-   Memory pools
-   Shared memory
-   Performance optimization
-   Embedded systems

------------------------------------------------------------------------

# Comparison Operators

``` cpp
vector<int> a={1,2};
vector<int> b={1,2};

cout<<(a==b);
```

Supported

``` text
==
!=
<
<=
>
>=
```

Comparisons are lexicographical.

------------------------------------------------------------------------

# Three-way Comparison (C++20)

``` cpp
auto result = (a <=> b);
```

Returns ordering information.

------------------------------------------------------------------------

# Iterator Invalidation Reminder

-   Reallocation invalidates all iterators.
-   `erase()` invalidates erased and following iterators.
-   `insert()` may invalidate iterators.

------------------------------------------------------------------------

# Time Complexity

  Operation                     Complexity
  --------------------- ------------------
  `begin()`                           O(1)
  `end()`                             O(1)
  `rbegin()`                          O(1)
  Iterator increment                  O(1)
  Iterator arithmetic                 O(1)
  Copy constructor                    O(n)
  Copy assignment                     O(n)
  Move constructor        O(1) (typically)
  Move assignment         O(1) (typically)
  `get_allocator()`                   O(1)

------------------------------------------------------------------------

# Best Practices

-   Prefer range-based loops when possible.
-   Use `const` iterators for read-only traversal.
-   Prefer move semantics when ownership transfer is intended.
-   Avoid using iterators after reallocation.
-   Custom allocators are rarely needed in everyday applications.

# Interview Questions

### What type of iterator does `std::vector` provide?

``` text
Random access iterator.
```

------------------------------------------------------------------------

### Difference between `begin()` and `cbegin()`?

``` text
cbegin() returns a const iterator that cannot modify elements.
```

------------------------------------------------------------------------

### Difference between copy and move?

``` text
Copy duplicates data.
Move transfers ownership of resources.
```

------------------------------------------------------------------------

### What is an allocator?

``` text
An object responsible for allocating and deallocating memory for a container.
```
