# C++ `vector`

- `std::vector` is one of the most commonly used containers in the C++ Standard Template Library (STL).
- It is a **dynamic array**, meaning its size can grow or shrink automatically during program execution.
- Unlike a normal array, you do **not** need to specify the size at compile time.
- `vector` stores its elements in **contiguous memory**, just like a C-style array.
- It supports **fast random access**, efficient insertion at the end, and automatic memory management.

# Why Do We Need Vector?

```cpp
int arr[3];
```

Arrays have:
- Fixed size
- Cannot grow automatically
- Manual memory management

Vector solves these problems:

```cpp
vector<int> v;

v.push_back(10);
v.push_back(20);
v.push_back(30);
v.push_back(40);
```

# Internal Working

A vector conceptually manages three pointers:

```text
begin
end
end_of_storage
```

Diagram

```text
begin                 end
  |                     |
  v                     v

+----+----+----+----+----+
| 10 | 20 | 30 |    |    |
+----+----+----+----+----+
                     ^
                     |
              end_of_storage
```

Meaning:

- **begin** → First element
- **end** → One past the last element
- **end_of_storage** → One past allocated memory

---

# Contiguous Memory

Unlike `deque` or `list`, vector stores elements together.

```text
--------------------------------
|10|20|30|40|50|
--------------------------------
```

Advantages:

- O(1) random access
- Excellent cache locality
- Compatible with C APIs (`data()`)

---

# Dynamic Growth

When the vector becomes full:

1. Allocate larger memory.
2. Move/Copy existing elements.
3. Destroy old elements.
4. Release old memory.
5. Update internal pointers.

Example:

Old

```text
---------------------
|10|20|30|40|
---------------------
```

After inserting `50`

```text
-----------------------------------------
|10|20|30|40|50| | | |
-----------------------------------------
```

---

# Growth Strategy

The C++ Standard does **not** specify the growth factor.

Many implementations grow approximately like:

```text
1 → 2 → 4 → 8 → 16 → 32 → ...
```

---

# Size vs Capacity

```cpp
vector<int> v;
```

Initially

```text
Size = 0
Capacity = 0
```

After inserting three elements (possible implementation)

```text
Size = 3
Capacity = 4
```

- **Size** = number of stored elements.
- **Capacity** = allocated storage before another reallocation is needed.

# Advantages

- Automatic resizing
- O(1) random access
- Cache friendly
- Efficient push_back()
- Easy to use

---

# Disadvantages

- Front insertion is O(n)
- Middle insertion is O(n)
- Reallocation invalidates iterators, pointers and references

---

# Interview Questions

### What is `std::vector`?

A dynamic array provided by the C++ STL.

### Is vector contiguous?

Yes.

### Why is random access O(1)?

Because memory is contiguous.

### Difference between Size and Capacity?

- Size = stored elements.
- Capacity = allocated storage.

### What happens when capacity is full?

The vector reallocates a larger memory block and moves/copies existing elements.
