# C++ `std::vector` --- Part 3

# All Modifier Functions

This chapter covers every major modifier used to change the contents of
a `std::vector`.

------------------------------------------------------------------------

# List of Modifier Functions

  Function           Purpose
  ------------------ ----------------------------
  `push_back()`      Add element at end
  `emplace_back()`   Construct element at end
  `pop_back()`       Remove last element
  `insert()`         Insert element(s)
  `emplace()`        Construct element in-place
  `erase()`          Remove element(s)
  `assign()`         Replace contents
  `clear()`          Remove all elements
  `resize()`         Change logical size
  `swap()`           Exchange contents

------------------------------------------------------------------------

# `push_back()`

Appends an element.

``` cpp
vector<int> v;
v.push_back(10);
v.push_back(20);
v.push_back(30);
```

Output

``` text
10 20 30
```

Complexity

-   Amortized **O(1)**
-   May become **O(n)** if reallocation occurs.

------------------------------------------------------------------------

# `emplace_back()`

Constructs the object directly at the end.

``` cpp
vector<pair<int,int>> v;

v.emplace_back(1,2);
v.emplace_back(3,4);
```

Avoids creating a temporary object.

------------------------------------------------------------------------

# `pop_back()`

Removes the last element.

``` cpp
vector<int> v={10,20,30};

v.pop_back();
```

Output

``` text
10 20
```

Complexity: **O(1)**

------------------------------------------------------------------------

# `insert()`

## Insert One Element

``` cpp
vector<int> v={10,30,40};

v.insert(v.begin()+1,20);
```

Output

``` text
10 20 30 40
```

------------------------------------------------------------------------

## Insert Multiple Copies

``` cpp
vector<int> v={1,2};

v.insert(v.begin(),3,100);
```

Output

``` text
100 100 100 1 2
```

------------------------------------------------------------------------

## Insert Range

``` cpp
vector<int> a={1,2};
vector<int> b={10,20,30};

a.insert(a.end(),b.begin(),b.end());
```

Output

``` text
1 2 10 20 30
```

------------------------------------------------------------------------

## Insert Initializer List

``` cpp
vector<int> v={1,5};

v.insert(v.begin()+1,{2,3,4});
```

Output

``` text
1 2 3 4 5
```

Complexity: **O(n)**

------------------------------------------------------------------------

# `emplace()`

Constructs an object directly at the specified position.

``` cpp
vector<pair<int,int>> v;

v.emplace(v.begin(),10,20);
```

------------------------------------------------------------------------

# `erase()`

## Erase One Element

``` cpp
vector<int> v={10,20,30,40};

v.erase(v.begin()+1);
```

Output

``` text
10 30 40
```

------------------------------------------------------------------------

## Erase Range

``` cpp
vector<int> v={1,2,3,4,5};

v.erase(v.begin()+1,v.begin()+4);
```

Output

``` text
1 5
```

Returns an iterator to the element following the last removed element.

Complexity: **O(n)**

------------------------------------------------------------------------

# `assign()`

Replaces all existing elements.

## Fill Assign

``` cpp
vector<int> v;

v.assign(5,100);
```

Output

``` text
100 100 100 100 100
```

------------------------------------------------------------------------

## Range Assign

``` cpp
vector<int> a={1,2,3};

vector<int> b;

b.assign(a.begin(),a.end());
```

------------------------------------------------------------------------

## Initializer List Assign

``` cpp
vector<int> v;

v.assign({10,20,30});
```

------------------------------------------------------------------------

# `resize()`

Increase size

``` cpp
vector<int> v={1,2};

v.resize(5);
```

Output

``` text
1 2 0 0 0
```

Increase with value

``` cpp
v.resize(7,9);
```

Output

``` text
1 2 0 0 0 9 9
```

Decrease size

``` cpp
v.resize(2);
```

Output

``` text
1 2
```

------------------------------------------------------------------------

# `clear()`

Removes every element.

``` cpp
vector<int> v={1,2,3};

v.clear();
```

Output

``` text
Size = 0
```

Capacity is usually unchanged.

------------------------------------------------------------------------

# `swap()`

Member function

``` cpp
vector<int> a={1,2};
vector<int> b={10,20};

a.swap(b);
```

or

``` cpp
swap(a,b);
```

Output

``` text
a : 10 20
b : 1 2
```

Complexity: **O(1)**

------------------------------------------------------------------------

# Combining Modifiers

``` cpp
vector<int> v;

v.push_back(10);
v.push_back(20);

v.insert(v.begin(),5);

v.erase(v.begin()+1);

v.emplace_back(100);

v.pop_back();

v.assign({7,8,9});
```

Final Output

``` text
7 8 9
```

------------------------------------------------------------------------

# Iterator Invalidation

  -----------------------------------------------------------------------
  Operation                           Iterator Invalidation
  ----------------------------------- -----------------------------------
  `push_back()`                       If reallocation occurs, all
                                      iterators become invalid

  `insert()`                          From insertion point onward; all if
                                      reallocation occurs

  `erase()`                           Erased element and following
                                      iterators

  `assign()`                          All iterators

  `clear()`                           All iterators

  `resize()`                          May invalidate if reallocation
                                      occurs

  `swap()`                            Iterators remain associated with
                                      their original elements but now
                                      belong to the other vector
  -----------------------------------------------------------------------

  `pop_back()`                   O(1)

  `erase()`                      O(n)
  `assign()`                     O(n)

------------------------------------------------------------------------

# Best Practices

-   Prefer `emplace_back()` for constructing complex objects.
-   Use `reserve()` before many `push_back()` operations.
-   Avoid repeated insertion at the beginning of a vector.
-   Store the iterator returned by `erase()`.
-   Remember that `clear()` removes elements but usually does not
    release capacity.

# Interview Questions

### Difference between `push_back()` and `emplace_back()`?

``` text
push_back() inserts an existing object.
emplace_back() constructs the object directly in the vector.
```

------------------------------------------------------------------------

### Does `clear()` free memory?

``` text
No. It removes elements but usually keeps capacity.
```

------------------------------------------------------------------------

### Which is faster: `insert()` or `push_back()`?

``` text
push_back() is usually faster because no elements need to be shifted.
```

------------------------------------------------------------------------

### What does `erase()` return?

``` text
An iterator to the element immediately following the last erased element.
```
